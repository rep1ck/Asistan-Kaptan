# Kaptan Asistanı

Ticari gemiler için Android seyir asistanı (**1.3.0**)

## Özellikler

### Seyir
- OSM / ESRI + OpenSeaMap
- COG yönlü üçgen gemi / AIS işaretleri
- Seyir planı (WPT, NM, kerteriz, ETA, yakıt tahmini)
- SOG / COG HUD
- Mesafe halkaları (0.5 / 1 / 2 / 5 NM)
- CPA / TCPA + tehlike çizgileri
- Çapa nöbeti, MOB, GPX panoya kopya
- AIS filtre (tümü / yakın / tehlikeli)

### Konfor
- Gece modu (kırmızı köprü)
- Ekranı açık tut (ayar)
- Güneş doğuş / batış
- Seyir defteri

### Veri
- True & relative rüzgar
- Basınç + 3 saat trend
- Türk liman / faro / boğaz listesi
- Yakıt (L/NM), LOA, beam

### APK
1. GitHub **Actions** → yeşil build  
2. **Artifacts** → `KaptanAsistani-APK`  
3. Eski APK’yı sil, yenisini kur  

Yardımcı araçtır. Resmi ENC/ECDIS yerine geçmez.
